# 04 使用者介面與互動

## 路由
| 路徑 | 頁面 |
|---|---|
| `/` | 首頁：一句使命、兩主題入口、隨機一題、模式切換 |
| `/practice/daily/`、`/practice/conservation/` | 主題題目列表（顯示完成狀態） |
| `/scenario/<id>/` | 單題作答頁（可分享） |
| `/toolkit/<id>/` | 討論引導卡：一張 A4 正反兩面，可用瀏覽器列印或另存 PDF（ADR-0033）；入口在圖鑑總覽與關於頁 |
| `/challenge/` | 綜合挑戰：混合兩主題的 5 題，全部答完再看結果（ADR-0032）；首頁與題目列表有入口 |
| `/guide/` | 圖鑑總覽（依卡別分組、收集狀態） |
| `/guide/<id>/` | 圖鑑卡 |
| `/terms/` | 名詞解釋 |
| `/me/` | 我的圖鑑：進度、徽章、匯出／匯入／清除 |
| `/about/` | 使命、非官方聲明、隱私、授權、參與方式、回饋 |
| `/updates/` | 更新紀錄：依月份列出手寫說明與新上架內容；無 `published` 的既有內容歸為「首批內容」（ADR-0024） |
| `/updates/feed.xml` | Atom 訂閱源：只含已審內容與手寫說明，最多 50 筆；各頁 `<head>` 有 `rel="alternate"` 連結 |

## 修訂揭露（ADR-0025）
- 圖鑑卡與情境題標題下顯示「最近修訂：日期（補充／勘誤）」，資料來自 `about` 指向本頁的說明，不用 `updated`；沒有說明的頁面不顯示。
- 修訂紀錄以 `<details>` 列出歷次說明，新到舊。圖鑑卡放在參考資料後；情境題放在作答後才出現的解說區塊內，避免提前透露答案，標題下的日期也不加連結。
- `impact: answer-changed`：情境題在題幹前、圖鑑卡在小檢核題目前顯示中性提示，不透露答案。題目列表中，修正當天或更早的作答改顯示「已作答（題目後來修正過）」，不顯示「答對」；作答紀錄、收藏與徽章不變。
- 有撤下公告且目前未發布的內容，匯入進度時仍保留其紀錄；畫面與徽章只依已發布內容計算。

## 作答流程
1. 讀情境（對話泡泡或引文樣式）。
2. 選擇「這段推理…」：`沒有問題` 或某卡名稱（3–4 個選項，打亂）。
3. 送出後顯示：對錯（圖示＋文字，不只靠顏色）、解說；進階模式加形式結構。結果框下方出現「下一題」與「回題目列表」。
   - 題目有 `## 換個位置想` 時，解說之後顯示同名區塊與固定提示「理解不等於同意…」（ADR-0029）。
4. 「更好的說法」區塊：先顯示「試著改寫看看」文字框（選填）→ 檢核清單自評 → 展開參考改寫。
5. 底部：相關圖鑑卡、下一題、隨機一題、「這題有問題？回報」。「下一題」依模式：基礎模式跳過進階題；沒有 JavaScript 時不分模式。

答錯時不扣分、不顯示紅色大叉，文案用「換個角度看看」。

### 進階題型（ADR-0022，只在進階模式出現）
全部採選擇式、共用同一個作答區與結果區，不做拖曳。不計分，只記錄是否完全答對。
- **`multi` 多重判讀**：核取方塊，題目說明「選出所有適用的，可能只有一個」；不提供「沒有問題」。送出後逐項標示，圖示一律搭配文字：✓ 正解，你選到了／↻ 正解，這次沒選到／✗ 這項不適用／△ 可接受，選不選都可以。
- **`validity-soundness` 有效 × 健全**：兩組單選，「推理形式有效嗎？」（有效／無效）與「前提可信嗎？」（可信／不可信／無法從題幹判斷），兩組都選才能送出，兩組都對才算答對。解說列出兩軸的答案與說明，以及推導出的健全與否。選項順序固定，不打亂。
- **`choice` 隱藏前提／形式辨識／反例選擇／鋼人練習**：單選，題目上方標示任務（例如「找出沒說出口的前提」「找出最強的版本」）。
- 「看答案與解說」列出每個選項的個別解說；沒有 JavaScript 時同樣收在這裡。
- `validity-soundness`、`choice` 沒有填改寫練習時，不顯示「更好的說法」區塊。

### 綜合挑戰（ADR-0032）
- 說明頁寫明：5 題、其中 1 題推理沒有問題、作答中不公布對錯、不計時、進行中的作答只存在這個分頁、送出後會覆蓋這些題目先前的紀錄。按「開始」後抽題。
- 抽題：已發布的單選判讀題，依目前模式（基礎模式不抽進階題）；恰好 1 題對照題、兩個主題都有、同一張正解卡最多 1 題；優先抽沒作答過的題。湊不齊條件時不顯示「開始」，改為說明與題目列表連結。
- 作答：一次一題，顯示「第 N／5 題」，選項打亂；沒選不能到下一題；可回上一題修改；最後一題按「全部送出」。換題時焦點移到該題標題；在前幾題按 Enter 視同「下一題」。
- 結果：只寫「這次答對 N 題（共 5 題）」，不附評語、等級或百分比；含做過的題目時加註。下方逐題回顧：判讀正確／換個角度看看（圖示＋文字）、你的判讀、正解、解說、換個位置想，以及完整題目的連結。按鈕「再挑戰一次」與兩個題目列表連結。
- 送出後逐題寫入 `answered`，與一般作答相同。
- 沒有 JavaScript：顯示需要 JavaScript 的說明與題目列表連結，不顯示作答區。

### 討論引導卡（ADR-0033）
- 螢幕上是一般頁面：標題、摘要、列印說明與「列印這張卡」按鈕（需要 JavaScript；沒有時只顯示說明文字）、正面與反面兩個區塊、頁尾（網址、授權、非官方聲明）、參考資料。
- 列印時：隱藏頁首、頁尾導覽、跳到主要內容、草稿提示、列印說明與參考資料；文字與框線一律黑色，不靠顏色區分；A4、邊界 12mm；反面從新的一頁開始，合計兩頁。
- 不在建置時產生 PDF；e2e 以列印媒體產生 PDF 確認頁數。

## 模式切換
- 頁首切換 `基礎｜進階`，存於 localStorage；預設基礎。
- 進階模式：顯示 `form`、`## 進階` 區塊、`difficulty: advanced` 題目。

## 名詞浮出說明
內文以 `[[premise]]` 標記名詞，建置時轉為可聚焦按鈕，點擊／Enter 顯示說明（popover），Esc 關閉。

## 視覺方向
自然田野手冊風格：紙張米白底、墨綠與土色、手繪感線條圖示。圖鑑卡以「野外圖鑑」排版（卡別色標＋英名＋一句話定義）。支援深色模式（prefers-color-scheme）。字型自託管（如 Noto Sans TC 子集）。
