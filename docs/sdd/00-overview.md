# 00 概觀

- 文件版本：v0.1（2026-09-26）
- 狀態：已確認設計，待實作
- 決策來源：2026-09-26 需求訪談（16 項決策，理由見 `docs/adr/`）

## 1. 目的
讓大眾透過互動練習認識邏輯定律與常見推理錯誤，**目標是讓討論變得更好，而不是贏過別人**。特別關注野生生物保育議題：保育討論常高度情緒化，好的推理能幫助各方降溫、聚焦證據。

## 2. 目標使用者
| 族群 | 模式 | 需求 |
|---|---|---|
| 一般大眾（高中以上） | 基礎 | 白話解說、生活化例子、5 分鐘內完成一輪 |
| 保育從業人員／志工／學生 | 進階 | 形式結構、推論規則、與資料解讀相關的偏誤 |

同一份內容透過 `mode` 切換深度，不維護兩套內容。

## 3. 成功指標（無流量統計前提下）
- MVP 內容 100% 經人工審核（`status: reviewed`）。
- 回饋表單每季至少有回應並完成分類處理。
- 任一新維護者僅靠 repo 文件，能在一天內完成本機建置並上架一題新內容。

## 4. 非目標（MVP 不做）
- 帳號系統、雲端同步、排行榜、留言區
- AI 即時評分或對話
- 英文版（結構預留）
- 流量統計
