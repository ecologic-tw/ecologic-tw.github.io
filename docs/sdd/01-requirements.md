# 01 需求

## 功能需求（FR）
| ID | 需求 | 優先 |
|---|---|---|
| FR-01 | 首頁：專案說明、兩個主題入口、「隨機一題」、模式切換 | MVP |
| FR-02 | 情境題作答：顯示情境 → 使用者判讀（選圖鑑卡或「沒有問題」）→ 顯示解說 | MVP |
| FR-03 | 解說分層：基礎解說；進階模式另顯示形式結構與推論規則 | MVP |
| FR-04 | 更好的說法：每題附 1–2 個參考改寫 | MVP |
| FR-05 | 改寫練習：自由輸入改寫 → 檢核清單自評 → 顯示參考改寫；不上傳 | MVP |
| FR-06 | 圖鑑：依卡別瀏覽、搜尋；每卡含定義、例子、何時不算謬誤、善意回應法、相關情境題 | MVP |
| FR-07 | 名詞解釋：列表＋搜尋；內文中名詞可點開浮出說明 | MVP |
| FR-08 | 個人圖鑑與進度：收集狀態、徽章，存 localStorage | MVP |
| FR-09 | 進度匯出／匯入（JSON 檔）與清除 | MVP |
| FR-10 | 回饋入口：每題與每卡提供「回報／建議」連結（Google 表單、GitHub Issue） | MVP |
| FR-11 | 分享：複製題目網址（不含個人作答） | MVP |
| FR-12 | 關於頁：非官方聲明、授權、隱私說明、如何參與 | MVP |
| FR-13 | 每日情境（依日期決定性選題，無獎勵） | v1.1 |
| FR-14 | 英文版 | 後續 |

## 非功能需求（NFR）
| ID | 需求 |
|---|---|
| NFR-01 | 純靜態輸出，GitHub Pages 可直接託管 |
| NFR-02 | 無 cookie、無第三方腳本、無金鑰（見 07） |
| NFR-03 | WCAG 2.1 AA：鍵盤可操作、焦點可見、對比度 ≥ 4.5:1、不單靠顏色表達對錯 |
| NFR-04 | 手機優先（≥ 320px 無橫向捲動） |
| NFR-05 | 效能：首頁 Lighthouse Performance ≥ 90；單頁 JS ≤ 50 KB gzip |
| NFR-06 | 內容 schema 錯誤時建置失敗 |
| NFR-07 | 關閉 JavaScript 時，圖鑑、名詞、情境與解說仍可閱讀（解說以 `<details>` 漸進增強） |
| NFR-08 | i18n 預留：內容路徑含語系、介面字串集中於 `src/i18n/zh-TW.ts` |
