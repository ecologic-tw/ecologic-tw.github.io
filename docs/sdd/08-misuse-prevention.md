# 08 防誤用與內容寫作準則

學邏輯的常見副作用是：拿謬誤名稱當武器、看到什麼都說是謬誤、以為指出謬誤就代表結論錯誤。本專案用結構與寫作準則預防。

## 結構性對策
1. **每張謬誤／偏誤卡必填**「何時不算謬誤」與「善意回應法」（schema 強制）。
2. **對照題**：每主題 15%–30% 題目推理沒有問題，正確答案是「沒有問題」。
3. **收錄「謬誤謬誤」卡**：推理有謬誤 ≠ 結論錯誤。
4. **徽章獎勵不亂貼標籤**（05：手下留情、謬誤的謬誤）。
5. **全站聲明**：頁尾「本站為社群教育專案，非任何機關立場；情境皆為虛構」。
6. **授權**：CC BY-SA 4.0 要求標示來源並以相同授權分享，讀者可追溯到最新勘誤版本。

## 寫作準則（撰寫與審核都要對照）
- **虛構**：人物用一般稱呼（阿明、里長、研究助理、社團版友）；不寫真實人名、機關名、團體名、媒體名、可辨識的具體事件。
- **物種與地點**：可使用常見物種（石虎、獼猴、黑面琵鷺…），但不寫精確地點、不寫敏感物種（如受盜採／盜獵威脅者）的棲地細節；地名最多到「某縣山區」層級。
- **立場平衡**：保育主題中，犯錯的一方**不可總是非保育方**。至少三分之一的保育題由支持保育的一方犯錯（例如：用訴諸情感或草率概括支持保育）。目標是讓人練習推理，不是替某立場背書。
- **不羞辱**：解說對事不對人；不使用「笨」「蠢」「被洗腦」等字眼。
- **區分推理與事實**：解說指出推理問題，但不宣稱結論必然錯誤；若涉及事實，需在 `sources` 附可靠來源，並可用 `supports` 說明支援哪項主張與適用範圍；不可把虛構案例數字說成來源的研究結果。
- **爭議議題**：涉及仍有社會爭議的保育議題（如遊蕩犬貓管理、放生、獵捕）時，情境應呈現多方觀點，須標記 `requiresSecondReview: true`，並由第二位不同審核者確認平衡。
- **爭點地圖**（ADR-0034）：只問每句話是哪一種分歧，不問讀者同意哪一方；每句寫明分類理由。一句話若有兩種以上同樣合理的答案，改寫或刪掉那一句，不靠 `acceptable` 硬撐；`acceptable` 只用於界線模糊、且解說能說明理由的情況。
- **多方觀點案例**（ADR-0036）：
  - 不設計「正確的一方」：每個角色都有合理的關切，也至少有一個容易被誤解的地方；角色以身分與關切描述，不用真實地名與團體名稱。
  - 理解不等於同意，溫柔不等於放棄事實：某個角色的事實主張證據較弱時，在背景或解說中說明並附來源，不必假裝各方證據一樣強。
  - 「共同點」的正解必須在每張角色卡都找得到依據；干擾選項用「只有部分角色同意」或「把某個角色的主張誇大成大家都同意」。
  - 「先問什麼」的正解是開放、針對該角色關切的問題；干擾選項優先用誘導式問題、推測動機或人格、只問是非、與該角色的關切無關。
  - 不問讀者自己同意哪一方。保育案例一律雙審；日常案例涉及爭議議題時才標 `requiresSecondReview: true`，由 Decision Owner 判斷並寫在 PR 說明。
- **換個位置想**（ADR-0029）：以「如果你是……」站到說話者與其他當事人的位置，用「可能」描述處境與擔心，不推論人格或動機；結尾給一句「可以怎麼問」；不替推理錯誤辯護，也不要求被攻擊的一方更有禮貌。理解不等於同意，溫柔不等於放棄事實。
- **心理學內容**：只討論說法與推理，不診斷任何人的心理狀態或人格；偏誤卡須標證據強度，爭議效應不當定論（規則詳見 12 §5）。
- **AI 協作**：AI 撰寫的內容標 `aiAssisted: true`，只能是 `draft`；人工審核重點為邏輯正確性（AI 常把合理推論誤標為謬誤）。

對照題的雙人審核設計見 ADR-0017；目前依維護人力暫不啟用，仍至少一人。此設定不取消爭議保育內容既有的第二審核要求。
