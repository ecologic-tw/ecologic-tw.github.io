# 05 八角框架（Octalysis）遊戲化設計

原則：**只用白帽驅動力**。這個網站在教人辨認說服與操弄，自身設計不得使用操弄手法（見 ADR-0003）。

| # | 核心驅動力 | 採用 | 本專案設計 |
|---|---|---|---|
| 1 | 史詩意義與使命感 | ✅ | 首頁使命「從各說各話，走向共同思考」；保育題解說結尾連結到「好的討論如何幫助保育」。使用者身分敘事：理性的步道同行者（非「糾錯者」）。 |
| 2 | 進步與成就 | ✅ | 個人圖鑑點亮（格數＝已發布圖鑑卡數，目前 30 張，含 1 張 draft）、主題完成度、學習里程碑徽章（見下表）。不計分數排名。 |
| 3 | 創意與回饋 | ✅ | 改寫練習＋檢核清單即時自評；參考改寫比較。 |
| 4 | 所有權與擁有感 | ✅ | 個人圖鑑、進度存於自己瀏覽器、可匯出成檔案帶走。 |
| 5 | 社交影響與關聯 | 輕度 | 分享題目網址、投稿新情境（表單／Issue）、貢獻者名單。**無排行榜、無人與人比較、不分享個人成績。** |
| 6 | 稀缺與渴望 | ❌ | 不鎖內容、不限時。 |
| 7 | 不確定性與好奇 | 輕度 | 「隨機一題」；v1.1 每日情境（依日期決定性選題，錯過無損失）。無抽獎、無隨機獎勵。 |
| 8 | 損失與避免 | ❌ | 無連續打卡、無進度衰退、無「再不做就…」文案。 |

## 徽章（MVP）
| 徽章 | 條件 |
|---|---|
| 初入步道 | 完成第 1 題 |
| 日常觀察者 | 完成日常主題全部 basic 題 |
| 保育觀察者 | 完成保育主題全部 basic 題 |
| 手下留情 | 答對 3 題對照題（辨認出「沒有問題」） |
| 換句話說 | 完成 5 次改寫練習自評 |
| 圖鑑收藏家 | 點亮全部已發布的圖鑑卡 |
| 謬誤的謬誤 | 讀完「謬誤謬誤」卡並答對其情境題 |

「手下留情」與「謬誤的謬誤」刻意獎勵**不亂貼標籤**，對應防誤用目標（08）。

## 文案禁止事項
- 不使用「只剩」、「快來」、「別錯過」、「連續 N 天」。
- 不以恐懼或羞辱激勵（如「你被騙了！」）。
