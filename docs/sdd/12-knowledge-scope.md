# 12 知識範圍與擴充路線

本章說明邏生門「教什麼、不教什麼」，以及後續擴充的順序。卡別與 schema 見 02、03；決策理由見 ADR-0020、ADR-0021。

## 1. 核心區分：真、有效、健全
邏輯主要研究**有效**（前提為真時結論不可能為假），不直接判定命題真假。

| 概念 | 問的是 | 誰負責判斷 |
|---|---|---|
| 真 | 這個命題符合事實嗎？ | 證據、調查、資料 |
| 有效 | 前提撐得住結論嗎？ | 邏輯形式 |
| 健全 | 有效，而且前提都真嗎？ | 兩者都要 |

這個區分支撐全站的防誤用設計：指出推理問題，不等於結論錯誤（謬誤謬誤卡）。

## 2. 哲學上的「真」（「什麼是真？」卡的內容範圍）
| 理論 | 核心主張 | 在本站的用法 |
|---|---|---|
| 符應論 | 命題與事實相符即為真；Tarski T 語句：「雪是白的」為真，若且唯若雪是白的 | 預設立場：情境題談的「真」都指符合事實 |
| 融貫論 | 與整體信念體系一致即為真 | 說明「多方紀錄一致」是判斷真假的證據 |
| 實用論 | 在探究與實踐中經得起檢驗的即為真 | 說明經營措施、預測需要長期檢驗 |
| 緊縮論 | 「P 為真」只是在斷言 P | 進階補充，不做題目 |

寫作原則：區分「什麼是真」與「我們怎麼知道」；不把共識等同於真，也不走向「一切都是相對的」。延伸主題（知識與 Gettier 問題、可否證性）列入後續。

## 4. 進階題型（ADR-0022，作答頁已實作）
進階模式目前只多顯示形式結構與進階題，作答方式與基礎模式相同。規劃中的題型全部採「選擇式」並共用同一作答元件，不做拖曳（無障礙成本高）：

| 題型 | 內容 |
|---|---|
| 多重判讀（多選） | 一段情境可能同時有多個問題；可設「可接受答案」 |
| 有效 × 健全判定 | 兩軸：推論有效嗎？前提可信嗎？ |
| 隱藏前提 | 選出論證沒說出口的前提 |
| 形式辨識 | 選出對應的形式結構 |
| 反例選擇 | 選出能推翻推論的反例 |

多選的判定：選中全部正解、未選錯誤選項即為答對；逐項顯示 ✓／✗／△，不計分。每個選項須有個別解說。

**資料模型與作答規則見 ADR-0022（提議）**：原規劃把 `answer` 改為 `answers[]`，會動到全部既有情境題（含已審題目）；ADR-0022 改以 `format` 欄位區分題型，既有題目不需修改。實作分三個 PR（schema 與檢查、作答頁與工具、內容），預計新增約 8 題進階題（每主題 4 題）。

## 5. 心理學內容範圍
**納入**：與推理和討論品質直接相關的認知偏誤與溝通心理。
**排除**：臨床心理、診斷、人格測驗與分類、心理健康建議。

| 階段 | 內容 |
|---|---|
| MVP | 3 張偏誤卡（確認偏誤、倖存者偏誤、可得性捷思）；新增證據強度欄位 |
| v1.1 | 擴充偏誤卡至 8–10 張候選：錨定效應、框架效應、基率忽略、後見之明偏誤、動機推理 |
| 爭議較多，需正反證據並陳（ADR-0038） | 溝通心理：身分保護認知、心理抗拒、風險知覺 |

### 心理學內容規則（補充 08）
1. **證據強度必填**：`robust`／`moderate`／`contested`，依 [ADR-0038](../adr/0038-evidence-based-review.md) 的最低門檻判定，不以研究篇數判定：
   - `robust`：至少一篇後設分析或系統性回顧，或大型預先登記的複製研究；沒有已知的重大複製失敗，也沒有未處理的嚴重發表偏誤疑慮。
   - `moderate`：至少兩個不同研究團隊的獨立研究；或有後設分析，但異質性高或有發表偏誤疑慮。
   - `contested`：有失敗的複製研究，或後設分析之間結論矛盾；本文須正反證據並陳、各附來源，並說明爭議與限制。
   - 未達 `moderate`（只有單一研究或同一團隊的研究，也沒有後設分析）的效應先保留草稿，不做成偏誤卡，等證據累積。
   - 以統計或邏輯錯誤為主的偏誤卡（例如倖存者偏誤），`robust` 指「錯誤本身成立」，不代表人們犯錯頻率的實證強度；卡上須說明這個意思（2026-09-30 補充）。
2. **避免複製危機地雷**：重複驗證失敗或效果有爭議的效應（例如回火效應、自我損耗、權力姿勢）不做成「已確立的偏誤」卡；若要介紹，只能以 `contested` 呈現並說明爭議。
3. **不貼標籤**：偏誤卡同樣必填「何時是合理捷思」與「善意回應法」；許多捷思在日常中是有用的。
4. **不診斷他人**：情境與解說不推論任何人的心理狀態、動機或人格，只討論說法本身。
5. **審核**：依可檢驗的理由，不依審核者的身分或人數（ADR-0038）。
   - 偏誤卡與含心理學研究主張的概念卡，須在 [`docs/review/evidence/<id>.md`](../review/evidence/README.md) 留證據判定紀錄，PR 說明放摘要與連結。
   - **反證搜尋必做**：沒做搜尋不能審核通過；搜尋過沒找到反證不阻擋發布，但不因此升級證據強度，卡上語氣要收斂（例如「目前查到的研究大多支持……」，不寫「已經證實」）。
   - 任何內容審核者都可以依紀錄審核；審核者都沒有心理學背景時屬「開放檢視」（[ADR-0030](../adr/0030-psychology-open-review.md)）：卡上未確認之處照實標示，並在更新紀錄公告、邀請覆核。有心理學背景的審核者同樣要留紀錄。
   - `contested` 偏誤卡與上表第三列的主題，正反證據並陳即可由一位審核者發布；同時涉及 08 所稱社會爭議議題時，仍依 08 雙審。
   - AI 可以起草紀錄與反證搜尋，但不得編造研究出處；無法確認的研究以「待查證」標示，最終證據強度由人工審核者決定。

## 6. 溝通與意義（2026-09-27 擴充）

- **非暴力溝通**：介紹觀察、感受、需要與請求，以及誠實表達、同理聆聽和容許拒絕；沿用 `concept`，不視為認知偏誤或邏輯定律，不加 `evidence`。來源支持框架介紹，不代表療效或普遍有效性證據；2026-09-27 由決策者審核發布，依 §5（ADR-0030）屬開放檢視，待具心理學背景的審核者覆核。
- **主觀意義、客觀意義**：依使用者確認採語言／溝通角度，不討論人生意義。「主觀意義」指說話者想傳達的意思；「客觀意義」是本站對公共語言慣例及可共享語境所支持理解的教學標籤，並非語言哲學的統一術語。
- **教學界線**：分清說話者意圖、公共解讀依據與聽者實際理解；不猜測人格或深層動機，不把「客觀」當成唯一解讀或真理保證。文獻對語意／語用分界仍有爭論，人工審核需核對此簡化方式。
- **交付範圍**：3 張卡各含日常與保育虛構例子、常見誤解及小檢核，另有 3 條名詞；使用者已於 2026-09-27 完成人工標記（Wang-Yi-Zhang）。沿用既有 schema 與發布門檻。本次不新增正式情境題，不改既有已審內容。
