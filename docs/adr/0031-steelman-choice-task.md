# ADR-0031 `choice` 題型新增鋼人練習任務

- 日期：2026-09-29
- 狀態：接受（2026-09-29，@Wang-Yi-Zhang）
- 決策者：@Wang-Yi-Zhang
- 回顧點：3 題試行草稿完成人工審核並有至少一位試讀者回饋後，決定是否擴充、修訂或停止；特別檢查正解之外是否有第二個合理答案

## 背景
[ADR-0029](0029-perspective-section-and-charity-card.md) 把「鋼人練習題」列為後續。目前讀者只能在「善意詮釋與鋼人論證」概念卡讀到這個方法，沒有練習的地方。

[ADR-0022](0022-advanced-question-formats.md) 的 `choice` 題型是單選自訂文字、每個選項附解說，任務（`task`）只決定標題與提示文字。練習「選出最強、最公允的重述」剛好符合這個結構。

## 決策
1. `CHOICE_TASKS` 新增 `steelman`，題目上方顯示「找出最強的版本」。作答元件、schema 規則與其他任務相同：3–4 個選項、恰好一個正解、每個選項都有 `note`、只出現在進階模式。
2. 寫作規則（補充 08）：
   - **正解**要保留說話者提出的全部理由，用最合理的方式整理，不超出對方說過的話；補上的結論或理由要保守，並在解說提醒「仍要用提問確認」。
   - **干擾選項**優先使用這幾種常見誤區：稻草人（說得更弱）、誇大（看似支持，其實更難成立）、換掉理由或推測動機、只抓到部分理由。
   - 說話者的主張可以是讀者未必同意的立場；解說說明「理解不等於同意」，不替主張背書。
   - 鋼人題沒有「犯錯的一方」，不計入保育題立場平衡的「由保育方犯錯」；但計入對照題比例的分母。含草稿時，保育題對照題比例會降到 3／21（約 14%），`npm run check` 只警告；只算已審題目加上 cons-021，則為 3／16（約 19%）。
3. 試行 3 題草稿：日常 2 題、保育 1 題。cons-021（步道路燈）經決策者判斷不屬 08 所稱的爭議議題，不需第二位審核者。

## 依據的資訊與假設
- 假設：從幾個重述中挑出最公允的版本，比只讀概念卡更能練習「先理解再回應」。
- 鋼人與 Rapoport 規則的來源沿用概念卡的 Dennett（2013），原文已由 @Wang-Yi-Zhang 核對（2026-09-29）。

## 已知風險
- **正解不唯一**：好的重述可能不只一種。緩解方式：干擾選項各有明確缺陷，並在試讀時檢查。
- **「最強」被誤解為「最極端」**：固定放一個誇大型干擾選項，在解說中說明誇大會讓主張更難成立。
- **正解最長、最周到，讀者可能只靠長度作答**：誇大型干擾選項也保留對方的全部理由，只在結論說過頭，讀者必須看出「超出對方的話」才能排除。試讀時檢查這個提示是否仍然明顯。
- **推測說話者心思**：正解只整理題幹中的理由，補充部分以提問確認。

## 考慮過的選項
- **另開新題型**：可以做成開放式改寫，但需要評分機制；本站無後端，也不使用 AI 評分（紅線 1）。
- **用 `hidden-premise` 任務**：鋼人會補上沒說出口的理由，但練習重點是「整體重述是否公允」，不只是找前提，標題會誤導。

## 後果
schema 與介面文字各多一個任務值；02、03、04、CONTEXT 與投稿指南同步更新。既有題目不受影響。
