# ADR-0037 我的應對工具箱（第一階段）

- 日期：2026-09-29
- 狀態：提議
- Decision Owner：@Wang-Yi-Zhang
- Review Point：上線後至少一位試讀者使用「我的圖鑑」並回饋後，檢視：讀者是否注意到工具箱、是否實際列印或引用裡面的句子、「每一次嘗試都算數」的文案是否讓人願意在答錯後回頭再試；再決定是否進入第二階段（記錄「答錯後再答對」，需要改進度格式，另寫 ADR）

## 背景
Decision Owner 希望讀者感受到「不用一開始就很厲害，要開始才有機會變厲害」，並且逐步累積應對工具。

目前的回饋幾乎只獎勵「答對」：點亮圖鑑要答對；答錯只顯示「換個角度看看」，之後再答一次就會覆蓋先前的紀錄。「我的圖鑑」顯示的是點亮了幾格，讀者帶不走任何可以實際使用的東西。

另一方面，19 張謬誤與偏誤卡已經寫好「善意回應法」（`charitableResponse`），討論引導卡（ADR-0033）也證明「一句可以直接說出口的話」是讀者最能帶走的東西。

## 決策
1. **「我的圖鑑」新增「我的應對工具箱」區塊**，放在「圖鑑收集」之後。每點亮一張有善意回應法的卡，就把那句話收進工具箱；依卡別（形式謬誤、非形式謬誤、認知偏誤）分組，附卡名與連結。
   - 建置時列出所有已發布、有善意回應法的卡，預設隱藏；前端依 `collectedEntries` 顯示已點亮的。文字都在建置時產生，不從進度檔讀取字串（07）。
   - 只顯示已收進的工具與數量「工具箱裡有 N 句回應」，不列出還沒收進的句子，也不寫「還差幾句」（05 文案禁止事項）。
   - 空的時候說明怎麼開始：「不用一開始就很厲害，要開始才有機會變厲害。試一題看看，答對後，那張卡的回應句就會放進來。」
2. **可以列印**：「列印我的工具箱」按鈕呼叫瀏覽器列印（與討論引導卡相同做法），工具箱是空的時候不顯示；列印時只印工具箱，黑白也清楚。
3. **強調嘗試**：
   - 練習進度的文字從「已作答 N／M 題，其中答對 K 題」改為「試過 N／M 題，答對 K 題」。
   - 情境題答錯時，結果下方多一句「每一次嘗試都算數：這次作答已經記在『我的圖鑑』，看完解說，隨時可以回來再試一次。」答對時不顯示。
4. **不改進度資料格式**，不新增徽章，不新增內容欄位；概念、思維定律與有效推論卡沒有善意回應法，第一階段不進工具箱。
5. 更新 04、05、CONTEXT 與 11 里程碑；上線時在同一個 PR 的 `updates.yaml` 加一則 `kind: feature`。

## 依據的資訊與假設
- 假設：可以直接說出口的一句話，比點亮的格數更能讓讀者感覺「我多了一個工具」。
- 假設：答錯時被告知「這次也算數、可以回來再試」，比只看到「換個角度看看」更願意再試。
- 成長型思維介入的研究效果多半偏小且有爭議。本 ADR 把它當成設計價值，不在網站上宣稱能改善思維或學習成效（與 ADR-0021 對證據強度的態度一致）。

## 已知風險
- 讀者可能把工具箱的句子當成萬用話術 → 每句都連回圖鑑卡，卡上有「何時不算謬誤」；工具箱說明寫明「先確認對方的意思，再決定要不要用」。
- 只收有善意回應法的卡，概念卡點亮後工具箱沒有變化，可能讓人困惑 → 說明文字寫清楚工具來自謬誤與偏誤卡；是否替概念卡補「思考工具」留待第二階段。
- 「隨時可以回來再試」會覆蓋先前的作答結果，答錯後再答對時，練習進度只顯示最新結果 → 這正是第二階段要處理的事，第一階段不改格式。

## 考慮過的選項（含不同意見）
- **新增「答錯後再答對」的徽章**：最直接呼應「開始才有機會變厲害」，但需要改進度格式與匯入驗證，留到第二階段。
- **依三步回應分組**（確認理解、找共同點、提問）：比依卡別分組更實用，但現有善意回應法沒有標註屬於哪一步，要逐張人工分類，屬於內容工作，留待之後。
- **列出尚未收進的句子（灰色）**：讓人知道還有什麼，但容易變成收集壓力，也等於提前看到答案的一部分，不採用。

## 後果
- 新增 `src/lib/toolbox.ts`（純函式）與「我的圖鑑」一個區塊、一段列印樣式，情境題頁多一句文案；不新增套件、不改進度格式、不影響綜合挑戰。
- 之後新增謬誤或偏誤卡時，寫好善意回應法就會自動進入工具箱。
