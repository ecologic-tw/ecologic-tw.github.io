# ADR-0039 思想源流：把思想家放在他留下的思考工具旁邊

- 日期：2026-09-30
- 狀態：提議
- 決策者：@Wang-Yi-Zhang
- 回顧點：試行的兩則（康德、莊子）發布，並有至少一位試讀者或具哲學背景的讀者回饋後。檢視：讀者是否打開「思想源流」、是否因此更理解那張圖鑑卡、原典核對紀錄是否幫助審核者發現錯誤、每則的審核時間（PR「投入時間」欄）、有沒有人把思想源流當成「某某說過，所以……」來用；再決定擴充（尼采、叔本華、黑格爾及非西方傳統）、修訂或停止

## 背景
決策者希望介紹哲學家對人類文明的貢獻。本站的主軸是練習判讀推理，不是哲學史，因此需要一個不偏離主軸的放法：

- **偉人名人堂不適合**：「對文明的貢獻」本身就有爭議，很難寫成審核得過的內容；而且一個教人辨認謬誤的網站，最不該出現「某某大師說過……，所以……」的訴諸權威。
- **思想家可以是思考工具的來源**：本站很多圖鑑卡處理的問題，哲學家早已討論過。讀者在學某個工具的當下，知道它從哪裡來、原本在回答什麼問題，比單獨讀一篇哲學家介紹更有用。
- **這類內容最容易出錯**：AI 與網路常見捏造或誤植的名言；經典有多種讀法；現代中文譯本多半仍受著作權保護。

試行先做兩位，一西一中：

| 思想家 | 原典 | 接到的圖鑑卡 |
|---|---|---|
| 康德 | 〈答「何謂啟蒙？」之問〉（1784） | 不當訴諸權威、訴諸武力（理論權威與實踐權威；行動的理由與信念的理由） |
| 莊子 | 《莊子・秋水》濠梁之辯 | 主觀意義、客觀意義（「安知」的兩種讀法） |

## 決策
1. **新增內容集合 `origins`（思想源流）**，每則介紹一位思想家的一個想法，以 `entries` 指向 1–4 張相關圖鑑卡。沒有獨立頁面：在這些圖鑑卡的頁面底部、參考資料之前，以可展開的「思想源流」區塊呈現，預設收合。
2. **欄位**：`id`、`title`（例：「康德：勇於運用自己的理智」）、`thinker`、`era`、`work`（原典篇名與年代）、`entries`、`summary`（80 字內），以及與其他內容相同的審核欄位（`status`、`reviewers`、`sources`、`contributors`、`aiAssisted` 等）。
3. **本文固定三段**，都必填：
   - `## 原典怎麼說`：原典段落與本站自己的白話翻譯；外文原典附原文關鍵句。
   - `## 和這張卡的關係`：這個想法在回答什麼問題，和圖鑑卡的哪一點相關，也寫出兩者**不同**的地方。
   - `## 常見誤讀`：至少一個流傳的誤讀，說明為什麼不對。
4. **寫作規則**（補充 08、12）：
   - **不以思想家背書**：不寫「某某說過，所以……是對的」；思想源流只說明想法的來歷，判斷仍回到圖鑑卡的理由。
   - **引文一律對照原典**：引用的原文要能在所列版本中找到；無法核對的句子不引用，改寫成摘要並標示「待查證」。不收流傳但查不到出處的「名言」。
   - **翻譯**：外文與古文由本站自行翻譯或改寫，不轉載現代中文譯本（著作權法第 52 條引用仍須合理範圍並註明出處）。原典已屬公有領域。
   - **多種讀法照實說**：經典有爭議的讀法時，寫「一種常見讀法是……」，並列出至少一個不同讀法或註明「學界讀法不一」。
   - **貢獻與限制並陳**：不做排名，不寫「最偉大」之類的評價；思想家的爭議或時代限制與主題相關時要提。
   - **來源**：至少一則原典（附版本或網址）加一則學術參考（例如史丹佛哲學百科）。
5. **原典核對紀錄**：比照 [ADR-0038](0038-evidence-based-review.md) 的證據判定紀錄，每則一份 `docs/review/origins/<id>.md`，記錄：引用段落所據的版本、翻譯的依據與取捨、查過的學術參考、不同讀法、未能核對的部分。審核通過的依據是這份紀錄可以檢驗的理由，不是審核者的身分。AI 可以起草紀錄，但不得編造出處。
6. **審核閘門**：與其他內容相同，只發布 `reviewed`；已審的思想源流只能指向已審的圖鑑卡。沒有具哲學背景的審核者時，比照 [ADR-0030](0030-psychology-open-review.md) 開放檢視，在更新紀錄公告、邀請覆核。
7. **第二步（本 ADR 不實作）**：「常見誤讀」情境題，例如把「子非魚，安知魚之樂」當成莊子的主張、把康德的「勇於運用自己的理智」讀成「不必聽專家」，用 `choice` 題型的隱藏前提任務練習。試行回饋後另開 PR。
8. **擴充順序**：試行後先補一位非西方傳統（例如墨家辯學、荀子〈正名〉、印度因明），再補尼采、叔本華、黑格爾，避免整區只有歐洲思想家。

## 依據的資訊與假設
- 假設：讀者在學某張卡時順便看到它的思想來源，比獨立的「哲學家專區」更容易讀到、也更不容易變成背誦。
- 假設：預設收合的區塊不會干擾只想學工具的讀者。
- 康德原文依 1784 年《柏林月刊》初刊本（Project Gutenberg 電子版）；莊子依中國哲學書電子化計劃的《莊子・秋水》。

## 已知風險
- **變相的訴諸權威**：讀者可能把思想源流當成支持結論的理由 → 寫作規則 4 第一點；每則的「和這張卡的關係」要寫出兩者不同之處；回顧點檢查。
- **解讀錯誤**：AI 起草的哲學解讀可能過度簡化 → 原典核對紀錄、多種讀法照實說、開放檢視與更新紀錄公告。
- **範圍蔓延**：可能逐漸變成哲學史網站 → 每則必須接到至少一張現有圖鑑卡；接不上的想法不收。
- **審核負擔**：每則需要讀原典與學術參考 → 試行只做兩則，依 PR 投入時間決定擴充速度。

## 考慮過的選項（含不同意見）
- **在圖鑑卡本文加選填段落**：不需要新集合，但修改已審卡要重新審核整張卡，而且同一位思想家接到多張卡時要重複寫。
- **思想家卡（獨立頁面）**：適合完整介紹，但偏離「學工具」的主軸，審核成本也最高；等試行有回饋再評估。
- **只做常見誤讀情境題**：最貼近練習主軸，但缺少讓讀者認識原意的地方；列為第二步。

## 後果
- 新增 `origins` 集合、`src/lib/origins.ts`（本文段落檢查）、`OriginNotes.astro` 元件；內容檢查、審核工具、載入工具支援新集合；`CONTENT_SCHEMA_VERSION` 升為 7。
- 03、06、08、12、CONTEXT 與 11 里程碑同步；發布時在同一個 PR 的 `updates.yaml` 加一則功能說明，並依第 6 點公告開放檢視。
- 不新增套件、不新增頁面或外連；原典與學術參考的網址放在 `sources`，沿用既有外連規則。
