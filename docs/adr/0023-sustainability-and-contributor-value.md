# ADR-0023 永續經營與貢獻誘因
- 日期：2026-09-27
- 狀態：提議（屬社群基本規則，依 `docs/sdd/10-governance.md`「決策方式」公開徵詢至少 14 天：公告 Issue #38，至 2026-10-11）
- 決策者：待指定（建議：管理員）
- 回顧點：實驗 #36 檢討時（2027-01）；第一個教育合作試點學期結束時；專案第一次收到任何形式的金錢或實物支持前

## 背景
邏生門以志工為主，目前所有角色由同一人承擔（`docs/sdd/10-governance.md` 角色名冊）。內容已累積到圖鑑卡 30 張、情境題 34 題，但有兩個結構性的限制：

1. **審核人力不足**：`requiresSecondReview` 的保育題需要兩位不同審核者，目前無法開放；AI 起草讓撰寫變快，審核卻沒有跟著變快（實驗 #36 正在量測）。
2. **沒有支撐維護的來源**：依賴更新、回饋整理、角色檢視都靠同一人的空閒時間。

紅線已排除廣告、追蹤、付費解鎖與排行榜，因此「讓人願意投入」不能靠向學習者收費或蒐集資料，而要讓每種投入者換得到對他有價值的東西，並讓維護成本有正當、透明的來源。

## 決策
1. **網站永遠免費、不追蹤、不設付費內容**。任何金錢或合作關係都不得影響內容判讀、題目立場或審核結果。

2. **讓貢獻的價值看得見**（對個人）：
   - 沿用 `contributors` 署名，之後新增「貢獻者」頁面，列出本人同意公開的名稱與貢獻。
   - 可應要求出具社群貢獻說明，內容限於實際參與的工作，並明寫「社群教育專案，非任何機關立場」（紅線 7）。
   - 持續維持「10 分鐘就能完成的小型貢獻」（ADR-0019），並在對外說明中強調。

3. **教育合作試點**（優先，同時解決審核人力）：
   - 先找一門課、試行一學期：學生以提案流程投稿情境題，授課教師經角色檢視登記為內容審核者，可擔任第二審核者。
   - 專案不蒐集成績或學生個資；署名只用本人同意的名稱或筆名，未成年者需另取得監護人同意，否則不署名。
   - 課程評分是教師自己的事，與內容是否發布無關；學生提案一樣走完整審核。

4. **保育團體合作**：可邀請具專業背景的人擔任審核者，列為貢獻者而不是背書者。立場平衡規則照樣適用；審核者所屬團體與題目議題有直接利害關係時，須在 PR 揭露，且不得是該題唯一的審核者。

5. **支撐維護的收入選項**（每一項實際啟動前，需再以 ADR 或公告 Issue 個別決定）：
   | 選項 | 條件 |
   |---|---|
   | 線下工作坊、講座 | 由個人提供服務，網站維持免費；收入歸屬事先公開說明 |
   | 捐款 | 只用公開帳目的平台，只放外部連結、不嵌入腳本 |
   | 補助 | 成效報告只用下列不追蹤指標；補助方要求流量統計時，必須先另寫 ADR |
   | 實體卡牌等衍生出版 | 依 CC BY-SA 標示來源並以相同授權釋出 |

6. **不追蹤的成效指標**（對外報告時使用）：已審內容數、貢獻者人數、回饋表單處理數、自願回報的課堂採用數、實驗 #36 的投入時間資料。

7. **明確不做**：廣告、販售或分享資料、付費解鎖內容、付費加速或保證審核、繞過立場平衡的贊助內容、貢獻者排行（指引 §25）。

## 依據的資訊與假設
- 已確認：角色名冊顯示所有角色集中於一人；`cons-001`、`cons-005`、`cons-009` 因缺第二審核者無法開放。
- 假設 1：教師有動機使用 CC BY-SA 的現成教材，並願意以審核換取課程素材。需要試點驗證。
- 假設 2：公開、可連結的署名對學生與初入行者有實際價值（作品集、推薦信佐證）。
- 假設 3：審核是主要瓶頸；實驗 #36 的結果可能推翻這點，屆時應調整優先順序。

## 已知風險
- **合作方影響內容**：以揭露、不得單獨審核與立場平衡規則降低；若發生，依學習回顧處理。
- **署名被誤解為官方背書**：署名與貢獻說明一律附非官方聲明。
- **學生與未成年者的個資**：不蒐集成績與聯絡資料；未成年者預設不署名。
- **收入歸屬爭議**：啟動任何收入前先公開說明歸屬與用途；沒有公開說明前不收取。
- **合作協調成本反而加重維護者負擔**：試點限一門課、一學期；回顧點時比較實際投入時間。

## 考慮過的選項（含不同意見）
- **維持純志工、不做任何合作或收入**：最單純，但單點失效與審核瓶頸會持續，維護者可能耗盡。
- **成立法人或協會**：資源與信任度較高，但行政與法遵成本遠超過目前規模；留待合作與收入穩定後再評估。
- **付費進階內容或會員制**：違反網站免費與白帽遊戲化原則（紅線 6、ADR-0003），不採用。
- **廣告或贊助商標示**：違反紅線 2、7，不採用。

## 後果
- 需要新增或更新的文件：「貢獻者」頁面、合作指南（教師與保育團體的參與方式與揭露規則）、PR 模板的利益揭露欄位、`docs/sdd/10-governance.md` 的角色名冊（合作審核者、合作窗口）。
- 每一項收入選項實際啟動前都要再決策；本 ADR 只訂原則與邊界。
- 實驗 #36 與教育試點的結果，會決定下一步優先投資審核工具，還是擴大合作。
