# ADR-0038 以可檢驗的證據判定取代以身分為主的審核門檻

- 日期：2026-09-29
- 狀態：接受（2026-09-29，@Wang-Yi-Zhang；接受時修改的兩點見文末）
- 決策者：@Wang-Yi-Zhang
- 回顧點：第一批三張依本流程審核的心理學卡發布後，或與 [ADR-0030](0030-psychology-open-review.md) 同一回顧點（約 2026-12-29），以先到者為準。檢視：證據判定紀錄是否幫助審核者或讀者發現錯誤、每張卡增加多少審核時間（PR「投入時間」欄）、有沒有卡因反證搜尋而降級或退回草稿、回饋表單與 Issue 意見；再決定維持、調整門檻或恢復以專業背景為主的審核

## 背景
目前有兩條規則靠「誰審核」與「幾個人審核」把關：

- **心理學內容**：[12 §5](../sdd/12-knowledge-scope.md) 第 5 條與 [ADR-0021](0021-bias-evidence-strength-and-psychology-scope.md) 要求具心理學背景的審核者確認；[ADR-0030](0030-psychology-open-review.md) 在沒有這樣的審核者時開放「開放檢視」，但 `contested` 偏誤卡和「需心理學審核者後」的主題仍要等專業審核者。
- **爭議內容**：[08](../sdd/08-misuse-prevention.md) 與 [ADR-0017](0017-content-accuracy-and-review-gates.md) 要求 `requiresSecondReview: true` 的內容至少兩位不同審核者。

決策者指出：即使具心理學背景，或多了第二個人，也不能保證內容沒有錯；把審核者的身分當作通過的依據，可能正是不當的訴諸權威。

本站的[訴諸權威卡](../../src/content/entries/zh-TW/appeal-to-authority.md)「何時不算謬誤」寫道：相關專家的證言是合理但可修正的理由，理由的強弱取決於專業是否切題、有沒有研究支持、其他專家是否同意。依這個判準，參考專家本身沒有問題，現行規則的問題有兩個：

1. **身分取代了理由**：規則只要求專業審核者「確認」，沒要求留下可檢驗的判斷依據。核准之後，讀者與之後的覆核者看不出為什麼判定為 `robust`。
2. **人數被當成品質保證**：程式只檢查不同帳號數（[10 治理](../sdd/10-governance.md)也寫明帳號欄位不能證明實際審核）。兩位審核者可能讀同一篇綜述、有同樣的盲點。

討論中也評估過「爭議題需兩篇以上研究支持」。這個方向是從人轉向證據，但篇數不是好指標：同一團隊的兩篇小樣本研究很容易湊到；自我損耗曾有大量研究支持，大型預先登記的多實驗室複製研究仍然失敗；只要求「支持」的研究也會鼓勵挑選證據。保育爭議多半是價值衝突，研究回答不了「該優先保護什麼」。

## 決策
1. **原則**：審核通過的依據是可以檢驗的理由，不是審核者的身分或人數。專業背景能提高判斷的可信度，但不是充分條件；每位審核者都要留下下面的證據判定紀錄。

2. **證據判定紀錄**：適用於偏誤卡，以及本文含心理學研究主張的概念卡（例如非暴力溝通、善意詮釋與鋼人論證）。每張卡一份，放在 `docs/review/evidence/<id>.md`（格式見 [該目錄說明](../review/evidence/README.md)），修訂時在同一份檔案累積；PR 說明只放摘要與連結。內容包括：
   - 每則來源的類型（後設分析、系統性回顧、預先登記複製研究、原始研究）、研究團隊與支持範圍（沿用 `sources.supports`）。
   - 反證搜尋：查詢詞、資料庫或搜尋工具、日期、結果。至少用「效應名稱＋replication／failed／meta-analysis」查過。
   - 未能查核的範圍，例如全文無法取得、只查了英文文獻。
   - 判定理由與剩下的不確定之處。卡上的不確定之處照實標示（沿用 ADR-0030）。

3. **證據強度的最低門檻**（取代「數篇數」）：

   | 證據強度 | 最低門檻 |
   |---|---|
   | `robust` | 至少一篇後設分析或系統性回顧，或大型預先登記的複製研究；沒有已知的重大複製失敗，後設分析沒有未處理的嚴重發表偏誤疑慮 |
   | `moderate` | 至少兩個不同研究團隊的獨立研究；或有後設分析，但異質性高或有發表偏誤疑慮 |
   | `contested` | 有失敗的複製研究，或後設分析之間結論矛盾；本文必須同時呈現支持與反對的證據及來源 |

   - **未達 `moderate` 的效應先保留草稿**：只有單一研究（或同一團隊的研究）、沒有反證也沒有後設分析時，不做成偏誤卡，也不新增第四級證據強度，等證據累積後再評估。
   - 「不同研究團隊」以作者群不重疊為原則；有疑義時寫進判定理由。

4. **反證搜尋必做，但找不到反證不阻擋發布**：
   - 沒做搜尋 → 不能審核通過。
   - 搜尋過、沒找到反證 → 可以發布，證據強度依支持證據的層級判定，不因「沒有反證」而升級；卡上語氣要收斂，例如「目前查到的研究大多支持……，尚未查到大型複製研究」，不寫「已經證實」。
   - 「沒有找到反證」不等於「證據強」，也不構成 `contested`。

5. **誰可以審核**：
   - 任何內容審核者都可以依證據判定紀錄審核心理學卡。審核者沒有心理學背景時，卡片屬於「開放檢視」（ADR-0030 的公告與標示做法不變），並邀請專業覆核。
   - 有心理學背景的審核者同樣要留紀錄；沒有紀錄的核准不算完成證據判定。專業覆核完成後，把帳號加入 `reviewers`，覆核改變結論時依 [ADR-0025](0025-revision-disclosure.md) 寫修訂說明。
   - **`contested` 偏誤卡與 12 §5「需心理學審核者後」的主題**（身分保護認知、心理抗拒、風險知覺）：必須有完整證據判定紀錄，並在本文正反證據並陳、各附來源；符合條件時，一位審核者即可發布，不再以心理學背景為必要條件，也不因屬心理學爭議而要求第二位審核者。內容同時涉及 08 所稱的社會爭議議題時，仍依 08 標 `requiresSecondReview: true`。
   - 臨床心理、診斷、人格測驗與心理健康建議仍然排除，本 ADR 不改變範圍。

6. **價值爭議的第二位審核者改為觀點平衡檢核**：`requiresSecondReview: true` 的保育（或日常）爭議內容，第二位審核者的任務是替較弱勢或未被充分呈現的一方做鋼人論證，檢查情境、解說與選項是否暗中偏向某一方。可行時優先找立場或背景不同的人擔任。反方觀點可以引用公開立場或研究，找不到來源的部分標「待查證」，不得編造。事實性主張仍依一般來源要求。兩人門檻與程式檢查不變。

7. **AI 的角色**：AI 可以起草證據判定紀錄、執行反證搜尋並建議證據強度；AI 找到的來源在人工核對原文前標「待查證」，最終證據強度由人工審核者決定。AI 不得自行標記 reviewed（紅線 4）。

8. **已發布內容的過渡**：已發布的心理學卡不退回草稿。在回顧點前或下次修訂時補上證據判定紀錄；補紀錄後證據強度需要改變時，依 ADR-0025 處理，至少屬「補充」。

## 依據的資訊與假設
- 假設：留下可檢驗的理由，比指定審核者身分更能讓錯誤被後來的人發現與修正。
- 假設：以證據層級（後設分析、獨立複製）判定，比計算研究篇數更能反映效應的可信度。
- 假設：本條屬內容審核流程，不是紅線、授權或社群指引等社群基本規則，依 [10 治理](../sdd/10-governance.md)「決策方式」以 ADR 由決策者決定，不需公開徵詢 14 天（與 ADR-0030 相同判斷）。若維護者認為屬於基本規則，改走公告 Issue 程序。
- 三級門檻是教學用的簡化，不是心理學界統一的證據分級標準；後設分析本身也可能受原始研究品質與發表偏誤影響，因此 `robust` 另外要求檢查複製失敗與發表偏誤。

## 已知風險
- **紀錄流於形式**：填了欄位但沒有真的查。若發生，會看到紀錄內容雷同、反證搜尋永遠「無結果」 → PR 核准者至少抽查一則來源的原文；回顧點檢視紀錄品質。
- **沒有專業背景的審核者誤讀後設分析**（例如異質性、發表偏誤校正）：若發生，會看到專業覆核或讀者回饋推翻判定 → 紀錄公開、卡片標示開放檢視；被推翻時依 ADR-0025 修訂，並以學習回顧檢討門檻。
- **`contested` 與「需心理學審核者後」主題的門檻降低**：這些內容可能由一位沒有心理學背景的審核者發布，錯誤較難在發布前被攔下。若發生，會看到讀者回饋或覆核指出漏列反證、把爭議效應寫成定論 → 要求正反證據並陳與完整紀錄；卡上已有 `contested` 標籤，並依 ADR-0030 屬開放檢視、在更新紀錄公告；PR 核准者須核對本文確實呈現反方證據。回顧點特別檢視這類卡的回饋。
- **審核成本上升、草稿變多**：若發生，會看到心理學卡長期停在草稿 → 回顧點依「投入時間」評估是否簡化紀錄格式。
- **反證搜尋受語言與付費牆限制**：紀錄須寫明未能查核的範圍，交給之後的覆核者補查。

## 考慮過的選項（含不同意見）
- **維持以心理學背景為主的審核（現況）**：專業判斷仍有價值，但沒有紀錄時無法檢驗，也讓內容依賴找不找得到特定身分的人。
- **爭議題需兩篇以上研究支持**：理由見背景；篇數容易湊到，也可能鼓勵只找支持的證據。
- **新增第四級證據強度（例如 `preliminary`）收單一研究**：需要改 schema 與頁面，也可能讓初步研究看起來像已確立的偏誤。決策者選擇先保留草稿。
- **證據判定紀錄只寫在 PR 說明**：不必新增檔案，但覆核者要從 Git 歷史找 PR，修訂後紀錄分散在多個 PR，也不在 repo 裡，不符合 10「文件即交接」。決策者接受時改採 repo 檔案；每張卡多一份檔案要同步，以 PR 模板的檢核項提醒。
- **`contested` 與「需心理學審核者後」主題仍須心理學背景審核者**：最保守，但又回到以身分把關。
- **`contested` 與「需心理學審核者後」主題需兩位審核者＋正反證據並陳**：原提議內容。目前只有一位維護者，實際上會一直停在草稿；決策者接受時改為一位審核者即可，以正反證據並陳與開放檢視公告補足。
- **把證據層級也套用到保育事實性主張**：保育事實同樣有證據強弱的問題，但範圍較大，本 ADR 不處理，另案評估。

## 後果
- [12 §5](../sdd/12-knowledge-scope.md) 規則 1（證據強度門檻與未達 `moderate` 保留草稿）與規則 5（審核改依證據判定紀錄）；表中「需心理學審核者後」改依本 ADR。
- [08](../sdd/08-misuse-prevention.md)「爭議議題」與「心理學內容」：第二位審核者的觀點平衡任務。
- [10 治理](../sdd/10-governance.md)角色表「內容審核者」的說明。
- [審核指南](../review/review-guide.md)：新增證據判定紀錄的寫法與反證搜尋方式。
- 新增 [`docs/review/evidence/`](../review/evidence/README.md)：紀錄格式說明。
- [PR 模板](../../.github/pull_request_template.md)：新增「證據判定紀錄」段與對應的檢核項目。
- [11 里程碑](../sdd/11-milestones.md)：已發布心理學卡補紀錄的清單。
- ADR-0021「已知風險」中「需心理學背景審核者」與 ADR-0030 決策第 1 條的「不適用」條款，改依本 ADR；兩份 ADR 其他決策不變，狀態欄註明部分由本 ADR 修訂。

不改內容 schema、程式檢查與依賴；`requiresSecondReview` 的兩人門檻不變。已發布卡上「待心理學背景的審核者判定」等文字屬已審內容，不在本次修改，補紀錄時一併檢視。

## 接受紀錄（2026-09-29）
- 決策者 @Wang-Yi-Zhang 接受本 ADR，並修改提議中的兩點：
  1. 證據判定紀錄改放 repo 檔案（`docs/review/evidence/<id>.md`），PR 說明只放摘要與連結。
  2. `contested` 偏誤卡與「需心理學審核者後」的主題，正反證據並陳即可由一位審核者發布，不需第二位審核者。
- 公開徵詢：與 ADR-0030 相同，目前沒有其他人參與，不走 14 天公開徵詢；之後有其他維護者或審核者加入時，可以對本條提出異議。

## 補充（2026-09-30，@Wang-Yi-Zhang）
補證據判定紀錄時發現，倖存者偏誤這類以統計或邏輯錯誤為主的偏誤卡，錯誤本身在統計上成立，不需要實驗證明；但「人們多常犯這個錯」缺少後設分析，決策 3 的門檻不太適用。決策者決定：這類卡的 `robust` 指「錯誤本身成立」，卡上須說明這個意思，不主張犯錯頻率的實證強度。已寫入 12 §5 規則 1。
