# ADR-0021 認知偏誤卡的證據強度與心理學範圍
- 日期：2026-09-27
- 狀態：接受（2026-09-27，@Wang-Yi-Zhang）
- 決策者：@Wang-Yi-Zhang
- 回顧點：v1.1 擴充偏誤卡前再檢視（第一個回顧點「既有 3 張偏誤卡補上 evidence 後改為全面必填」已於 PR #27 完成）

## 背景
使用者提出評估納入心理學內容。心理學效應受複製危機影響，部分廣為流傳的效應重複驗證失敗；偏誤名稱也和謬誤名稱一樣，可能被拿來貼標籤。

## 決策
1. 圖鑑卡新增選填欄位 `evidence: robust | moderate | contested`，只適用 `bias`；頁面顯示證據強度標籤與說明。
2. **過渡期**：`draft` 偏誤卡必填；既有 3 張 reviewed 偏誤卡暫不強制，AI 不代填，以免未經審核修改已審內容。
3. 心理學範圍：納入與推理、討論品質相關的偏誤與溝通心理；排除臨床心理、診斷、人格測驗。規則見 12 §5 與 08。
4. MVP 不新增偏誤卡；擴充與溝通心理列入 v1.1 之後。

## 依據的資訊與假設
- 三級分類足以提醒讀者「這不是定論」，又不會過度複雜。

## 已知風險
- 證據強度的判定本身需要專業 → 需心理學背景審核者；在此之前新增卡片維持 draft。
- 過渡期可能被遺忘 → 已列入里程碑與交接紀錄。

## 考慮過的選項
- 不做心理學：失去與「好好討論」最相關的內容。
- 全面擴充：審核能力不足，錯誤風險高。

## 後果
既有 3 張偏誤卡需人工決定 evidence 值（交接紀錄附 AI 建議值供參考，非結論）。
已完成：@Wang-Yi-Zhang 於 2026-09-27 決定三張卡的值（確認偏誤、倖存者偏誤 `robust`，可得性捷思 `moderate`），過渡期結束，所有偏誤卡改為必填（PR #27）。
