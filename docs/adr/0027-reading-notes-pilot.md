# ADR-0027 閱讀筆記轉化為既有教材的兩題試行
- 日期：2026-09-28
- 狀態：接受（2026-09-28，@Wang-Yi-Zhang）
- 決策者：@Wang-Yi-Zhang
- 回顧點：兩題提案完成來源核對、內容審閱及至少一位自願試讀者試讀後，依理解卡點、答案歧義與編輯成本決定擴充、修訂或停止；無審核人力則留提案。

## 背景

使用者提供 100 份閱讀筆記，希望整理並評估網站納入方案。素材含科普、哲學、心理、關係、文學及自我管理；不少與既有卡片重疊，亦混有私人練習、書摘與宣傳文案。逐書匯入會偏離推理教育使命，並擴大查證及審核負擔。

## 決策

以下決策已接受（2026-09-28），尚未開始試作：以跨書的學習問題整理素材，優先沿用既有圖鑑、情境提案及自評流程；先試 [評估文件](../review/reading-notes-assessment.md) 中的 P3、P5，再決定是否補足六題。新偏誤卡及書目專區留後續，不新增 schema、套件或資料收集。不調整紅線與 reviewed 門檻。

## 依據的資訊與假設

- 依 [SDD 12](../sdd/12-knowledge-scope.md)，本站納入推理、認知偏誤與溝通，排除臨床、診斷及心理健康建議。
- 假設：將書中啟發轉成既有概念的虛構練習，比建立完整書摘區更能幫讀者學會判讀。
- 假設：至少有一位自願試讀者與合適審核者願意承接小型提案；尚未取得承諾，無工期保證。
- 本批評估不是原書內容查核；素材適合程度不代表研究結論可信度。

## 已知風險

- 成功敘事、心理效應或文學類比被誤當實證 → 每題記錄來源對應與適用條件；不確定處保留待查。
- 私人練習／書摘被整批公開 → 原檔保留私人目錄，repo 只留必要分類、原創改寫與來源定位。
- 將所有二選一都判謬誤，或將溝通框架當心理診斷 → 先做合理二選一對照；試讀檢查是否學會區分條件。
- 新增題目排擠 M5 與既有來源修補 → 擴充非上線前置，兩題後即進回顧點，不自動擴大。

## 考慮過的選項（含不同意見）

- 補既有教材：修改量小，仍須防止只是換皮重複題；本案推薦。
- 新增概念／偏誤卡：可補知識缺口，但研究與心理學審核成本較高，按既有 SDD 路線另排。
- 主題延伸閱讀頁：有助持續閱讀，但尚無需求證據；新集合的來源、審核與維護方式需另議。
- 完整筆記或療癒專區：可保留私人閱讀脈絡，但超出本站目前使命，不採用於本試行。

## 後果

接受時原始筆記不動，未建立正式內容或發布；試行項目列入里程碑。試作依 [現有情境協作流程](../review/scenario-contributions.md) 起草；人工審核完成前皆留 draft。

### 2026-09-28：提前轉入草稿、與試讀並行起草新偏誤卡
- **決定**（決策者 @Wang-Yi-Zhang）：P3、P5 不等試讀完成即轉入正式草稿（daily-020、cons-020）；方案 B 的兩張偏誤卡（框架效應、後見之明偏誤）與試讀並行起草。
- **理由**：讓人類能以 `npm run dev` 在網站版面中檢視內容，而不只讀提案檔。
- **不變的部分**：一律維持 `draft`，正式建置不會公開；標記 reviewed 仍依原審核規則。偏誤卡依 SDD 12 §5 需具心理學背景的審核者判定證據強度，在此之前不公開。回顧點不變：兩題試讀後再決定是否擴充。
- **風險**：新卡與試讀並行，可能在尚未驗證教材方向前增加審核負擔。緩解：只做兩張、都在 SDD 12 v1.1 名單內；基線偏移不在路線圖上，仍留後續。
