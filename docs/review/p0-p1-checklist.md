## 來源查核

全部內容已補至少一項書目；新增來源以 `supports` 說明適用範圍。既有文獻、作者與連結仍需人類查核，不能只看「有網址」。情境是虛構的，概念文獻不是對話中的研究數字出處。

- [ ] **同一性／充足理由**：SEP 的 Identity、Principle of Sufficient Reason；確認概念與引用一致。
- [ ] **問卷**：AAPOR Best Practices；確認不把大樣本或高回覆率當成無偏保證。
- [ ] **混淆**：Howards 等（2012）的因果圖分析，人工開啟原文核對。自動讀取遇到網站驗證，已核對索引摘要，不能當作已逐段讀完全文。
- [ ] **未偵測**：MacKenzie 等（2002）的占據率研究；USGS 索引摘要可查，本文連線未成功，請由人類開啟 DOI／原文核對。不能將一般偵測理論當作特定池塘或石虎調查資料。
- [ ] **道路通道**：Rytwinski 等（2016）的統合分析；效果依圍籬、物種及設計而異，不能當作所有通道均有效的保證。
- [ ] **窗戶碰撞**：USFWS 的資料背景為美國；不可直接聲稱臺灣各地死因排序相同。
- [ ] **天然產品**：NCCIH 與 EPA 魚藤酮資料分別支持人類補充品風險及水生毒性；不可互相替代，也不能推定虛構除草劑的成分。
- [ ] **心理學文獻**：Tversky 與 Kahneman 1973／1974 的 DOI 原文回應 403，請核對書目與定義；未將其標示為已讀完原文。
- [ ] **其他卡片與名詞**：邏輯與調查概念來源只支持相應概念，不足以替保育政策或個別醫療判斷背書；若保留額外實證主張，人工再補對應來源。
