# 證據判定紀錄

依 [ADR-0038](../../adr/0038-evidence-based-review.md)，偏誤卡與本文含心理學研究主張的概念卡，每張卡在本目錄有一份紀錄，檔名與卡片 `id` 相同（例如 `hindsight-bias.md`）。紀錄讓審核者、覆核者與之後接手的人看得到**為什麼這樣判定**，而不只是**誰核准了**。

- 新增或修改這類卡時，在同一個 PR 新增或更新紀錄；PR 說明只放摘要與連結。
- 修訂時在同一份檔案累積，不另開新檔；舊的判定由 Git 歷史與「修訂歷程」保留。
- AI 可以起草紀錄與執行反證搜尋；AI 找到、尚未由人核對原文的來源標「待查證」。最終證據強度由人工審核者決定。
- 證據強度的門檻、反證搜尋與誰可以審核，以 ADR-0038 與 [12 §5](../../sdd/12-knowledge-scope.md) 為準；本檔只說明紀錄格式。

## 格式

複製下面的區塊，替換角括號內的文字。表格可依實際來源增減列數。

```markdown
# 證據判定紀錄：<卡名>（`<id>`）

- 卡別：<bias／concept>
- 證據強度：<robust／moderate／contested；概念卡填「不適用」>
- 開放檢視：<是／否>（審核者都沒有心理學背景時為「是」，依 ADR-0030 公告）
- 最近判定：<YYYY-MM-DD>，<@審核者帳號>；PR：<連結>

## 來源

| 來源 | 類型 | 研究團隊 | 支持範圍 | 已核對原文 |
|---|---|---|---|---|
| <作者（年份），DOI> | <後設分析／系統性回顧／預先登記複製研究／原始研究> | <主要作者群> | <支持哪項主張、限制> | <是／否／待查證> |

## 反證搜尋

| 日期 | 查詢詞 | 資料庫或工具 | 結果 |
|---|---|---|---|
| <YYYY-MM-DD> | <效應名稱 replication / failed / meta-analysis> | <例如 Google Scholar、Crossref> | <找到什麼；沒找到也照寫> |

## 未能查核的範圍

<例如：某篇全文無法取得、只查了英文文獻。沒有則寫「無」。>

## 判定理由

<對照 ADR-0038 的門檻，說明為什麼是這個證據強度；`contested` 要說明正反兩方各有哪些證據。>

## 剩下的不確定

<卡上照實標示的部分，以及覆核者應優先檢查的地方。>

## 修訂歷程

- <YYYY-MM-DD>：<首次判定／改了什麼、為什麼>（<PR 連結>）
```
