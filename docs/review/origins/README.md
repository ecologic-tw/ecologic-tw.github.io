# 原典核對紀錄

依 [ADR-0039](../../adr/0039-origins-of-ideas.md)，每則思想源流在本目錄有一份紀錄，檔名與思想源流的 `id` 相同。紀錄讓審核者與覆核者看得到**引文從哪裡來、翻譯怎麼取捨、有哪些不同讀法**，而不只是**誰核准了**。

- 新增或修改思想源流時，在同一個 PR 新增或更新紀錄；修訂時在同一份檔案累積。
- AI 可以起草紀錄；AI 找到、尚未由人核對的內容標「待查證」。不得編造出處或引文。
- 寫作規則以 ADR-0039 第 4 點為準；本檔只說明紀錄格式。

## 格式

```markdown
# 原典核對紀錄：<標題>（`<id>`）

- 接到的圖鑑卡：<id 清單>
- 開放檢視：<是／否>（審核者都沒有相關哲學背景時為「是」）
- 最近核對：<YYYY-MM-DD>，<@審核者帳號或「AI 起草，待人工核對」>；PR：<連結>

## 引文與版本

| 引文（原文） | 版本或網址 | 本站翻譯 | 已核對原文 |
|---|---|---|---|
| <原文句子> | <版本、頁碼或段落> | <白話> | <是／否／待查證> |

## 翻譯的取捨

<哪些詞有多種譯法、為什麼這樣譯。>

## 學術參考與不同讀法

<查過哪些學術參考，各自怎麼讀；本則如何呈現不同讀法。>

## 未能查核的範圍

<例如：只核對電子版、未比對初刊本；某種讀法尚未找到學術出處。沒有則寫「無」。>
```
