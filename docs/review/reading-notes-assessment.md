# 閱讀筆記的網站納入評估

本文件是編輯評估草案，用於判斷一批閱讀筆記可如何轉化為 EcoLogic 的思辨教材；不是已審教材，也不是對原書、作者或筆記撰寫者的完整學術評鑑。

建議採「跨書整理學習問題，優先補既有情境題」，而不是把每一份閱讀筆記直接轉成一張知識卡。初篩結果為：6 份優先改寫、22 份待補資料／查證候選、51 份保留為編輯或延伸閱讀靈感、21 份現階段不納入。分類單位是「筆記」，不能直接換算成可發布卡片數。

> 隱私原則：公開版只保留完成編輯判斷所需資訊，不公開私人關係、第三人身分、練習回答、可識別生活情境或不必要的個人閱讀側寫。完整逐筆評估保留於內部工作文件。

## 範圍與判讀方式

- 對象：100 份 Markdown 閱讀筆記；逐份檢視可見的心得、摘記與書目資訊，優先候選另讀相關段落。
- 「筆記線索」只代表筆記中可見的主題；「轉化方向」是教學設計建議，不代表原作者原話，也不代表對筆記撰寫者本人的人格、信念或動機判斷。
- 書目資訊、出版宣傳、引文、個人心得、練習回答及外部連結屬於不同證據層級，不混為一談。
- 私人關係、第三人身分、可識別生活事件與私人練習不進入公開版評估；若某候選素材只能依賴這些資訊才能理解，則不納入公開教材。
- 圖片附件、其他筆記連結及未讀取內容不作推論依據。
- 正式內容仍須依專案既有知識範圍、內容 schema 與審核規則處理；心理學或爭議保育內容需額外領域審核。

## 整理後的學習主線

| 主線 | 共同學習問題 | 適合網站的切入 | 邊界 |
|---|---|---|---|
| 思辨與認識限制 | 我們的理解和世界本身可能差多少？ | 區分觀察、推論、假設；找反例；釐清用詞 | 不把謙虛或直覺變成人格測驗 |
| 溝通與關係 | 我聽到的是對方的意思，還是自己的解讀？ | 善意重述、具體請求、辨認偷換主張 | 不診斷動機、不教治療，不保證化解衝突 |
| 決策與成功敘事 | 成功故事能證明方法有效嗎？ | 倖存者偏誤、相關與因果、必要／充分條件 | 不提供投資建議、不認定努力必然成功 |
| 自然與保育 | 感官、分類與立場會漏掉什麼？ | 偵測限制、定義、抽樣與多方論證 | 科普或文學不是特定物種／政策的直接證據 |
| 哲學、宗教與文學 | 不同視角如何改變理解？ | 作為問題靈感、語境與類比練習 | 信念、隱喻、敘事不能冒充科學證據 |
| 自我管理與生活實踐 | 如何生活、復原或改變習慣？ | 少量供編輯參考 | 多數超出本站推理教育範圍，不直接轉為教材 |

整體素材較適合發展成「如何提出有根據、且願意修正的說法」這條學習線，而不是整理成某一種人生觀、幸福觀或人格側寫。

## 優先教材方向

公開版只保留「教材方向」，不列完整閱讀履歷與逐本私人筆記判斷。

### 1. 事實、判斷與隱藏前提

- 練習把觀察、推論、價值判斷與預設前提分開。
- 優先使用自行撰寫的虛構情境，不直接重製原書架構。
- 若涉及原書主張，補版次、頁碼與可追溯來源。

### 2. 觀察、評價與善意重述

- 練習區分對方原話、自己的轉述與對動機的推測。
- 不把某一溝通框架是否被遵守直接判成「邏輯正確／錯誤」。
- 不使用真實私人關係案例作教材。

### 3. 選項是否窮盡

- 練習辨認錯誤兩難，也提供「確實只有兩個可行選項」的對照題。
- 不預設所有問題一定存在第三條路。

### 4. 成功敘事與缺失樣本

- 練習辨識只展示成功案例時，被省略的失敗樣本或條件。
- 不從個別成功故事直接推導普遍有效的方法。

### 5. 調查方法與結論範圍

- 練習判斷有限時段、有限方法或有限樣本能支持到什麼程度的結論。
- 生物與心理學的具體事實需查原始研究或可靠綜述。

### 6. 定義、分類與價值判斷

- 練習判斷兩人是否在使用相同定義或分類標準。
- 把「怎麼分類」與「怎麼評價」分開。

## 素材品質與優先查核

1. **科學主張需逐項查核**：涉及心理效應、生物機制、演化、比例或因果時，不因書籍知名度而直接視為可靠證據。
2. **性別、人格與群體概括不可直接套用個人**：若素材將群體傾向寫成個人規則，暫不作教材依據。
3. **「第三選擇」不是永遠存在**：選項是否窮盡要看情境條件。
4. **心理或溝通框架不等於推理規則**：框架可作澄清工具，但不能直接當成真偽判準或診斷工具。
5. **文學、宗教與哲學素材需保留類型差異**：可用於觀點比較、語境與類比，不直接冒充實證證據。
6. **既有網站內容也須接受同樣來源標準**：不能因已發布或已 reviewed 就免除來源核對。

## 採納後的具體步驟與完成條件

1. 先處理既有來源缺口，同時只認領少量試作題。
2. 每個候選主張建立編輯紀錄：來源筆記、原書版次／頁碼、自己的改寫、擬連卡片、來源支持範圍、待查事項。
3. 一題只測一個可判讀目標，並提供「何時合理」或控制組案例，降低看到關鍵字就貼標籤的風險。
4. 不為了硬塞內容而錯用既有題型；需要新任務形式時另提設計決策。
5. 至少安排一位試讀者及適合領域的審核者，記錄歧義、可能的多解與誤診風險。
6. 書摘、出版簡介與私人心得不整批複製；逐項確認引文出處、改寫程度及公開範圍。
7. 製題後執行專案既有內容檢查、測試、引用與比例核對。

## 公開版與內部版的界線

### 公開版可以保留

- 評估方法與限制
- 主題統計與教材方向
- 虛構化後的題目提綱
- 查核原則與審核流程
- 不含個人側寫的整體結論

### 內部版才保留

- 100 份筆記的逐筆分類
- 可反推出個人生活情境的心得摘要
- 私人練習、實踐紀錄與行動清單
- 第三人資訊，即使已使用代稱但仍可能由情境辨識
- 任何只對作者本人有用、對教材判斷沒有必要的閱讀軌跡資訊
