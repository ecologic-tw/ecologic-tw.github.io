# 情境提案工作區

這裡保存可不完整的情境與修訂提案，不會被網站載入，也不影響正式內容建置。先貢獻一段對話、一個來源或一句改寫即可；仍須遵守虛構、無個資與內容授權規範。

操作見 [情境協作指南](../../docs/review/scenario-contributions.md)。使用 `npm run scenario -- new` 或 `edit` 建立提案，在同一份檔案補內容、`contributors` 與 `nextSteps`；完成後透過 `promote` 驗證並轉為 draft。轉入後工具會把提案移到 [`promoted/`](promoted/)，保留作為紀錄、不再編輯，也不和進行中的提案混在一起；後續修訂改用新的 edit 提案。
